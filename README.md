# Here you will find all the necessary documents for the Data-Driven Expansion of Standardized Competency Profiles

## Folder structure:

### **notebooks:**
```
The notebooks folder forms the core of the project. It contains all the Jupyter notebooks for data preparation, data analysis, profile extension, evaluation, and further processing steps. The methods and workflows implemented here constitute the essential technical foundation of the approach described in the dissertation.
```
### **ArchiMate**
```
The ArchiMate folder contains the enterprise architecture models used in the project in the .archimate and .xml formats.
```
### **docs & data:**
```
The “docs” and “data” folderscontain all data sets from the 3rd DSR cycle. This includes both raw data from external sources and interim results and final results generated during processing by the notebooks. 
```
